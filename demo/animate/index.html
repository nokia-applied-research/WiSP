Step 1 / 5 · the setup

One budget, two hungry tenants

Step 2 / 5 · the problem

A static split wastes the budget

KV pool sized once, offline, for the worst case → ~56% sits idle here.
Experts capped at 36 → the rest page from CPU every step.
Idle KV bytes cannot help the experts that are actually starving.
Step 3 / 5 · observe

MV-WSA measures the real demand

Peak KV working set: ~44% of the allocated pool.
Expert miss rate high → bytes are worth more as residency.
This agent trace simply does not need a large KV pool.
